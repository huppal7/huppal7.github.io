# huppal7.github.io

My personal portfolio — a warm, editorial single-page site with a hero, about, experience timeline, project showcase for [ApplicationHQ](https://github.com/huppal7/ApplicationHQ), skills, education, and contact.

Live at [huppal7.github.io](https://huppal7.github.io).

Built with plain HTML, CSS, and JavaScript — no framework, no build step. Warm humanist design: cream-on-ink palette with a single terracotta accent, Fraunces + Newsreader serif typography, and a paper-grain texture. Hosted directly via GitHub Pages from the `main` branch.
