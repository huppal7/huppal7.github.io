Selected work

03
ApplicationHQ

A full-stack job-application tracker. Parses recruiting emails into draft applications and keeps a per-user pipeline — every record, event, and analytics view scoped to a JWT-verified owner, never a client-supplied ID.

Source
  • Owner-scoped data. Backend verifies the Clerk JWT on every request; a user requesting someone else's application gets 404, not 403.
  • Email import. Recruiting emails get parsed into a draft application — company, role, status, notes — automatically.
  • Dashboard. Table and Kanban views with search, status filtering, and inline editing.
  • Event history. Every create and status change is recorded per application, not just the current state.
  • Analytics. Status breakdown computed client-side from the same owner-scoped API the dashboard uses.
  • Tested. 52 backend tests covering auth, ownership isolation, CRUD, and email-parsing edge cases.
